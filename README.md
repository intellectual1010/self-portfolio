## Getting Started

Clone the repository:

```bash
git clone https://github.com/intellectual1010/self-portfolio
```

Enter the project:

```bash
cd self-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production Build

Create a production build:

```bash
npm run build
```

Run the production version locally:

```bash
npm run start
```
